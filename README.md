# android-kit

Terminal-first Android development command center.

`ak` wraps Gradle, adb, and the official Android CLI so common device and
project operations work from any directory without editing commands.

## Status

Design and MVP scaffolding in progress. No public binary yet.

## Planned commands

```bash
ak project add
ak project list
ak use <project>
ak run
ak layout
ak screenshot
ak web
ak paths
ak doctor
ak uninstall
```
